Research

The thread through my work is getting reliable intelligence out of constrained resources. It started with scarce labels — semi-supervised learning — and now runs through scarce compute: what survives when a model has to answer inside a latency budget, on a device, next to a person or a vehicle.

  • Hardware-aware inference for vision transformers and vision–language models
  • Quantisation trade-offs (FP32 / FP16 / INT8) and what they actually cost in accuracy
  • On-device generative pipelines — speech-to-text → language model → text-to-speech on Jetson, Raspberry Pi and STM32MP2
  • Real-time driving-scenario video understanding, benchmarked across NVIDIA H100 and Jetson Orin Nano
  • Semi-supervised learning: distance-based sample weighting for trees and deep networks

Enhancing classification with semi-supervised deep learning using distance-based sample weights

A. Abedinia, S. Tabakhi, V. Seydi

10th International Conference on Machine Learning Technologies (ICMLT) · IEEE · Helsinki, 2025 · oral

Weights training samples by their distance to the test distribution, down-weighting noisy and out-of-distribution examples. Helps most when labels are few or classes are imbalanced.

arXiv Code PyPI Write-up

Building semi-supervised decision trees with semi-CART algorithm

A. Abedinia, V. Seydi

International Journal of Machine Learning and Cybernetics · Springer · 15(10), 4493–4510, 2024

Extends CART so unlabeled data shapes the split criterion, through sample weights derived from the distance between labeled and unlabeled instances.

Open source

The published methods ship with installable implementations.

  • semideep Python

    Distance-based sample weighting for semi-supervised deep learning. Companion to the ICMLT paper. pip install semideep

  • semicart Python

    Semi-CART: semi-supervised decision trees with distance-based weights. Companion to the IJMLC paper. pip install semicart

  • cartgo Go

    CART in Go — fit, predict, save, load — for low-latency serving paths.

  • rust_decision_tree Rust

    Decision trees written from scratch in Rust, to see what tree learning costs when you control the memory layout.
